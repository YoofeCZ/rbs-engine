# Third-party software and assets

RBS Engine itself is MIT licensed (see [LICENSE](LICENSE)). It builds on the following
open-source projects. Libraries are downloaded by CMake at configure time and linked
statically into the `rbs` executable.

| Component | Used for | License |
|---|---|---|
| [raylib](https://github.com/raysan5/raylib) 5.5 | window, input, OpenGL renderer, audio, image/model/sound loading | zlib/libpng |
| [Lua](https://www.lua.org) 5.4 | gameplay scripting | MIT |
| [nlohmann/json](https://github.com/nlohmann/json) 3.11 | maps, prefabs, settings | MIT |
| [Inter](https://github.com/rsms/inter) (`base/fonts/ui*.otf`) | editor and menu UI font | SIL Open Font License 1.1 |
| [DejaVu](https://dejavu-fonts.github.io/) (`base/fonts/mono.ttf`, `title.ttf`) | console, titles, HUD | Bitstream Vera license / public domain changes |

raylib bundles further libraries that end up in the executable, among them
[GLFW](https://www.glfw.org) (zlib), [miniaudio](https://miniaud.io) (public domain / MIT-0),
[stb_image, stb_truetype and friends](https://github.com/nothings/stb) (public domain / MIT),
[cgltf](https://github.com/jkuhlmann/cgltf) (MIT), [dr_wav, dr_mp3, dr_flac](https://github.com/mackron/dr_libs)
(public domain / MIT-0), [qoi](https://github.com/phoboslab/qoi) (MIT), [m3d](https://gitlab.com/bztsrc/model3d) (MIT)
and [jar_xm / jar_mod](https://github.com/kd7tck/jar) (public domain). See raylib's `LICENSE` and the
headers in its `src/external/` folder for the exact terms.

Full font license texts are in [base/fonts/LICENSES.md](base/fonts/LICENSES.md).

## Game assets

All textures, 3D models, sounds and maps in `base/` and `mods/` were generated by the
scripts in [`tools/`](tools) for this project and are released under the same MIT license
as the engine. Replace them freely.
